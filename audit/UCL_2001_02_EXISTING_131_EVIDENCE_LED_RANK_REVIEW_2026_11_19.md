## I. 별도 후보 오류·누락 추후 검증

- 기존 후보는 131명 모두 유지하였으며 소속·주 포지션·ID를 임의 수정하지 않았다.
- UEFA 2002 기술연구그룹 올스타 후보 명단과 대조 시 기존 후보에 없는 선수: Fernando Galetto, René Henriksen, Jens Nowotny, Frank de Boer, Bixente Lizarazu, Samuel Kuffour, Jorge Costa, Stéphane Henchoz, Owen Hargreaves, Emerson (Deportivo), Fran, Edgar Davids, Hasan Şaş, Clayton Ferreira Cruz. (새로 추가하지 않음)
- 데이터 ID 검토 요망: `ucl-2001-02-cosmin-contra-niculescu`는 현재 '클라우디우 니쿨레스쿠' 레코드와 매칭돼 있어 사람 이름과 ID 간 의미상 불일치 가능성이 있음. ID는 보존.
- 출전 경기수 누락, 선발/교체, 포지션의 시즌 실제 출전 비중, 생년월일 누락은 독립 증거 조사 대상으로 남긴다.
- 데이터에 기록된 일부 수치/전술 서술은 후속 대조 전까지 '원본 저장 수치' 또는 '초안 판단'으로만 취급한다.

## J. 저장 데이터 자동 정합성 검사

- **PASS** — 선수 131명 / ID 중복 없음
- **PASS** — 131명 전원 티어 입력
- **PASS** — 131명 전원 포지션 순위
- **PASS** — 포지션별 순위 1..N 연속
- **PASS** — 티어와 순위 간 등급 역전 없음
- **PASS** — Best XI 11명 / 중복 없음 / 포지션 일치
- **PASS** — 원본 131명 후보 추가/삭제 없음
- PASS — 등록 선수 ID·소속·포지션 보존 및 기존 경기/참가팀 데이터 변경하지 않고 선수 평가 필드 수정
- 미실행 — 실제 GitHub Pages 인터랙티브 UI 테스트 및 CI; 성공했다고 보고하지 않는다.
- 미완료 — UEFA 공식 경기 로그와 출전 시간 전원 재대조, 최근 3시즌 정밀 평가, 모든 생년월일 검증
