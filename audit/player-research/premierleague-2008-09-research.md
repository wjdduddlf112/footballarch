# Premier League 2008-09 — 선수 후보·티어·포지션 순위 DRAFT

- 제라드의 선수 기록상 주 포지션은 CAM, Best XI 표시 위치는 CM. 램퍼드 역시 CM이며 두 명의 CM을 4-4-2 전술 칸에 표시.
- 2008-09 PFA XI를 참조하되 그대로 복사하지 않음. 예컨대 포츠머스 글렌 존슨은 다음 시즌 유럽대항전 미진출 구단 소속이므로 선정 불가. 맨유 라이언 긱스는 최상급 시즌을 보냈지만 램퍼드(PL 37선발, 12골 10도움)의 지속적 중원 생산성과 제라드(16골 9도움)를 우선 평가.
- 맨유 비디치의 수비 기여, 첼시 아넬카 19골 득점왕, 맨유 호날두 18골, 토레스 14골의 개인 실적을 반영. 팀 순위·우승 자체는 가점 없음.

## 5. 검증 수준 및 잔여 사항

- **122명 전체** 2008-09 PL 출전, 선발, 골 기록 입력 및 시즌 한정 구단별 출전표 대조. 제공처 교차 확인까지 완료했다는 의미는 아님.
- **7개 팀 × 11명 = 77명** 구단별 주전 배정. 해당 포지션 주전+후보 인원 상한과 중복 선수 검사 통과.
- **Best XI 11명**의 2006-07, 2007-08 리그 선발 수 입력 완료(외국 리그 포함, 소속/리그 구분).
- **90명**은 직전 두 시즌 중 한 시즌 이상 정확한 선발 기록 누락. 이들의 티어는 정성적 DRAFT이며 최종 3시즌 비교 검증 불완전.
- **122명 전체** 경기별 최다 출전 포지션 확인은 미완료. 생년월일 입력은 완료했지만 개별 선수 이중 출처 확인까지는 미실시.
- 아넬카의 2007-08 성적은 볼턴+첼시 합산(28선발 11골), 첼시 소속만 추출한 10선발 1골과 혼동 금지.
- 아스널 클리시 2008-09 골 기록은 FBref 0골과 Statbunker 1골의 불일치를 기록하고 FBref 값을 우선 사용. 일부 도움/득점은 제공처 산정 기준이 다름.
- 구조 검사와 GitHub 커밋은 실제 사이트 클릭·엠블럼 검사와 별개. **Node CLI 검사 미실행, 실배포 화면 검증 미확인, 사용자 승인 전.**
