## 8. 평가 근거·검증 불가 항목

- **잠정 티어 선수 129명**: JSON의 선수별 `tierRationale`, `threeSeasonAssessment`, `sources` 참조. 개인 능력 및 UCL 역할에 관한 정성 평가이며 최근 3시즌 수치를 완전 독립 검증했다고 의미하지 않음.
- **미평가 119명**: 단일 경기 출전만으로 3시즌 티어를 정량·정성 확정할 근거가 부족해 `tier:null` 유지.
- **UCL 스탯 확인 18명**: FBref 클럽별 2005/06 Champions League Standard Stats의 MP, Starts, Min, Goals, Assists 근거. 나머지는 수치를 추정하거나 0으로 대체하지 않음.
- **팀별 11명**: 시즌 최빈 선발 조합으로 독립 검증하지 않았음. 역사적 전술 후보 11명이며 결승 한 경기 명단에만 의존한 확정 명단이 아님.
- **생년월일**: 248명 값 존재하지만 일부는 기존 미승인 국내리그 JSON에서 이전한 것으로 별도 출처 교차 검증 필요.
- **기록 검증**: 조별리그 자체 산식 및 285골 합산 확인; 원자료 전 경기 날짜/결과를 UEFA 공식 경기별 원본과 일대일 재검증하는 추가 절차 필요.
- **배포**: GitHub 커밋과 GitHub Pages 반영, 실제 브라우저 JS 구동·상세 필터 검증은 별개.
