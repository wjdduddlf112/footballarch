## 0. 작업 요약과 평가 절차

- 해당 시즌: UEFA Champions League **2007-08**. 다른 UEFA 대회는 범위 밖.
- 본선 32개 구단·8개 조·조별리그 96경기·토너먼트 29경기 = 125경기, **330골**.
- 평가 대상: **16강 진출 구단 16팀**에 한정.
- 개인 기량 3시즌 평가 기간: **2005-06 → 2006-07 → 2007-08**(최근 시즌이 최대 가중치). UCL 개인 기여에 초점. 팀 전체 성적과 토너먼트 진출 단계는 개인 티어 점수에 직접 가산하지 않음.
- 구단별 대표 XI 11명 × 16 = 176명, 포지션별 최대 후보 1명씩 123명, 총 **299명**. 모든 주전·후보 역할은 해당 대회 경기별 출전과 시즌 최빈 기용 포지션 독립 검증 전에는 잠정.
- 299명 모두 한글 이름·원어명·구단 원어명·생년월일 필드 존재(일부 출생일은 미승인 국내리그 아카이브에서 재사용; 독립 이중 검증 미완료).
- 299명 모두 S~C- 체계 내 **임시 티어·해당 포지션 순위 초안**. 선수별 정성 판단이 많으며 개별 대회 출전과 과거 2시즌 기록의 독립 검증은 아직 끝나지 않음.
- UEFA 공식 득점/도움/선방 일부 상위 선수 수치를 직접 기입했고, 기록을 모르는 선수의 통계는 0으로 조작하지 않고 null 보존.
- 4-2-3-1 Best XI 초안 11명. 사용자 승인 전 `proposed_unapproved`.
- GitHub Pages 및 실제 브라우저 검증 여부는 별도 워크플로 결과를 확인해야 함.
